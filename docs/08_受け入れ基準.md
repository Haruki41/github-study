# 受け入れ基準

[← 要件定義書に戻る](../要件定義書.md)

これを満たせば完成とみなす条件です。

| No. | 確認内容 | 関連する機能 |
|---|---|---|
| 1 | `index.html` を開くと、青い背景（`#0079bf`）に3列が表示される。 | F-01 |
| 2 | 各列でテキストを入力して追加すると、その列の末尾にカードが表示される。 | F-02 |
| 3 | 空欄（空白のみを含む）で追加ボタンを押す、または Enter キーを押しても、カードは増えず、赤文字で「タスクの内容を入力してください」と表示される。文字を入力し始めると、その表示は消える。 | F-02 |
| 4 | カードを別の列にドラッグ＆ドロップすると、その列に移動する。 | F-03 |
| 5 | 「×」を押すと、カードが消える。 | F-04 |
| 6 | ページを再読み込みしても、カードが同じ列に残っている。 | F-05 |
| 7 | ブラウザを閉じて開き直しても、カードが同じ列に残っている（IndexedDB に保存されている）。 | F-05 |
