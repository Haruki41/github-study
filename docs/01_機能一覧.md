# 機能一覧

[← 要件定義書に戻る](../要件定義書.md)

アプリが持つ機能の一覧です。各機能の詳しい振る舞いは [02_機能要件](./02_機能要件.md) を参照してください。

| ID | 機能 | 概要 | 優先度 |
|---|---|---|---|
| F-01 | ボード表示 | 3列（未着手／進行中／完了）を横に並べて表示する | 必須 |
| F-02 | カード追加 | 各列からカードを追加する（空欄時はエラー表示） | 必須 |
| F-03 | カード移動 | ドラッグ＆ドロップで別の列へ移動する | 必須 |
| F-04 | カード削除 | 「×」ボタンでカードを削除する | 必須 |
| F-05 | データ保存 | IndexedDB に保存し、再読み込み後も復元する | 必須 |
| F-06 | カード編集 | 既存カードの文言を後から変更する | 任意（次回） |
| F-07 | 列の追加・名称変更 | 列を増やす、名前を変更する | 任意（次回） |
| F-08 | 同一列内の並べ替え | 列の中でカードの順番を変更する | 任意（次回） |

- 優先度：必須＝今回必ず作る／任意＝余裕があれば作る
- 機能IDは、[画面設計](./04_画面設計.md)・[ユースケース](./05_ユースケース.md)・[データベース設計](./06_データベース設計.md) から参照される。
