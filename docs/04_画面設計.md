## 3. 部品一覧
| 番号 | 部品 | 内容 | 関連機能 / DB操作 |
|---|---|---|---|
| ① | 見出し | アプリ名を表示する | - |
| ② | 列 | 列名とカードを縦に並べる。ドロップ先になる | F-01 / `GET /api/board` |
| ③ | カード | タスクの文言を表示する。ドラッグできる | F-03 / `PATCH /api/cards/{id}`（未実装） |
| ④ | 削除ボタン「×」 | カードを削除する | F-04 / `DELETE /api/cards/{id}`（未実装） |
| ⑤ | 入力欄・追加ボタン | 入力して「追加」または Enter でカードを追加する | F-02 / `POST /api/cards`（未実装） |
| ⑥ | エラー表示 | 空欄時に赤文字で「タスクの内容を入力してください」を表示する | F-02 |
| ⑦ | 検索窓 | キーワードを入力すると、含むカードだけを各列に表示する。空にすると全件に戻る | F-09 / `GET /api/board?q=`（未実装） |

API の詳細は [06_データベース設計](./06_データベース設計.md) を参照。③④⑤は、対応する API ができるまで画面に出さない（まず表示と検索だけを作る）。

## 4. 画面の状態
| 状態 | 見た目 |
|---|---|
| 通常 | 青い背景（`#0079bf`）に3列を表示する |
| 読み込み中 | 「読み込み中…」と表示する |
| API に接続できない | 「サーバーに接続できません」とエラーを表示する。画面は真っ白にしない |
| 列にカードがない | 入力欄だけを表示する（書き込み機能の実装後）。表示のみの間は空の列を表示する |
| 検索で該当なし | 3列は残し、「該当するタスクがありません」と表示する |
| 入力エラー | ⑥を赤文字で表示し、入力欄の枠も赤くする。入力を始めると消える |
| ドラッグ中 | ドロップできる列を強調表示する（案） |

## 5. 表示ルール
- 色：背景 `#0079bf`、エラーは赤
- 文字はすべてテキストとして表示する（React の自動エスケープを使い、HTML として解釈させない）
- 幅：PCのブラウザ向け。スマートフォンは対象外
